# 投稿・編集ガイド

ネット上の既存キャラクターと公開作品のみを投稿してください。図鑑を埋めるための新しい形象生成は禁止です。

1. 原作者、元の公開ページ、原図 URL を探します。Bilibili の動画・投稿 ID を保持し、投稿者とキャラクター原作者を区別します。
2. `content/candidates/` または Source Issue フォームに候補を登録。不明な作者・日時・公式性・条件は「不明」とします。
3. 画像固有の利用条件を確認。出典のみ確認できる場合は `kind: reference`、`downloadable: false` とし、画像を転載しません。
4. 再配布と改変が可能なら `content/sources/<id>.json` に根拠、全クレジット、元の公開ページ、確認日、ファイルを記録。GitHub は 40 桁コミット SHA に固定。Bilibili は元画像 URL と許諾声明を保存。
5. `npm run collect` と `npm run assets` を実行。原本を維持し、派生ファイルから親のハッシュを参照します。
6. 名称・説明・作品情報・外見・出典注記を中国語、英語、日本語で用意します。
7. テスト・ビルド後、PR を提出し確認を受けます。

原図に忠実な寸法・余白・形式調整のみ対応。生成型再描画、自動背景除去、ニューラル超解像は含みません。透かし・クレジットを消さず、補間を細部復元と呼ばないでください。原図更新には新 ID・版を使用し、上書きしません。削除時には履歴・配布版・キャッシュへの対応も必要な場合があります。
