# 素材工坊使用指南

[中文](STUDIO.zh.md) · [English](STUDIO.en.md) · [日本語](STUDIO.ja.md)

从角色详情或某张素材的“在工坊中使用”进入，也可以打开工坊选择本地图片。处理在浏览器中完成；本地图片、作者和声明不会上传或自动加入公开库。

1. 选择作品与具体素材，再选完整立绘（768 × 1024）、头像画布（512 × 512）、介绍卡或自定义。尺寸包含署名区，是本站默认值，不是平台规格。
2. 只有对应用途已核对的预设可选。当前 13 组素材可完整适配，3 组 CC BY-NC-SA 作品可制作介绍卡；其他作品不因“可下载”而开放介绍卡。介绍卡的个人标题不代表官方设定。
3. 高级参数可调整比例、尺寸、留白、背景与格式，调整后切换为自定义。图像始终完整等比适配；圆形画布也保留原图四角。放大不恢复细节。
4. 查看带署名的最终预览。成品和署名分区，不覆盖作品。如果声明太长，增大画布或缩短本地填写的文字；不会静默截断。
5. 导出 ZIP，内含带署名的成品、原始字节、来源与处理记录、已采集素材的证据文件。分享时保留成品中的署名和条件；也可复制完整署名。下载文件生成成功不代表浏览器已永久保存到磁盘。

本地图片可选择两种来源：

- **已有公开来源**：填写 HTTPS 原作链接、作者和使用条件。制作介绍卡还需确认有权排版并再分享。填写的来源和条件属于用户提供，未经本站独立核验。
- **本人原创、尚未公开发布**：填写作者与使用声明，并确认原创、未公开及加工/分享权利。无需公开链接，旧链接不会进入此分支的导出。记录保留用户声明、未独立核验状态、导出时间和原图 SHA-256。

更换本地图片会清空上一张的作者、来源、声明和确认，避免误用。语言切换会重新加载页面：公开素材选择保留，本地图片与填写内容不写入网址，需重新选择和填写。

来源文件或证据校验失败时不生成 ZIP，可在恢复后重试。原图始终保留；本站未进行自动抠图、改绘或生成细节。公开投稿仍需完整的来源采集和审核流程。
