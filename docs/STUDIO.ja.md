# 素材工房ガイド

[中文](STUDIO.zh.md) · [English](STUDIO.en.md) · [日本語](STUDIO.ja.md)

キャラクターや素材の「素材工房で使う」から開くか、工房でローカル画像を選択します。処理はブラウザ内で完結し、画像・作者・声明をアップロードしたり、公開図鑑に追加したりしません。

1. 作品と素材を選び、立ち絵（768 × 1024）、アイコン用キャンバス（512 × 512）、紹介カード、カスタムから選択します。サイズにはクレジット欄を含み、プラットフォームの規格ではなく当サイトの初期値です。
2. 用途が確認されたプリセットのみ選択できます。現在13組で全画像の比率維持リサイズ、CC BY-NC-SA の3組で紹介カードを利用可能。ダウンロード可能というだけでは紹介カードを許可しません。個人の見出しは公式設定を示しません。
3. 詳細設定では比率・サイズ・余白・背景・形式を調整し、変更するとカスタムに切り替わります。円形でも四隅を含め画像全体を保持します。拡大は細部の復元ではありません。
4. クレジット付きの最終プレビューを確認します。作品とクレジットを別領域に配置し、重ねません。文字が収まらない場合はサイズを大きくするか入力文を短くしてください。無断で切り詰めません。
5. クレジット付き画像、原本、出典・加工記録、収集素材の根拠ファイルを含む ZIP を保存します。共有時は画像内のクレジットと条件を保持してください。全文のコピーも可能です。ファイル生成成功はディスクへの保存完了を保証しません。

ローカル画像は次の2種類から選べます。

- **公開済みの作品**：HTTPS の原作 URL・作者・利用条件を入力。紹介カードにはレイアウトと再共有の権利確認も必要です。入力情報はユーザー提供で、独立検証は未実施です。
- **本人の未公開オリジナル作品**：作者・利用声明を入力し、本人の未公開作品であり、加工・共有の権利があることを確認します。公開 URL は不要で、以前の URL はこの分岐の出力に含めません。声明・未検証状態・出力日時・原図 SHA-256 を保存します。

別の画像を選ぶと前の作者・出典・声明・確認を消去します。言語を切り替えるとページを再読み込みします。公開素材の選択は保持されますが、ローカル画像や入力情報は URL に保存しないため、再入力が必要です。

原本や根拠を読み込めない、またはハッシュが一致しない場合は ZIP を生成せず、復旧後に再試行できます。原本は保持し、自動切り抜き・描き直し・細部生成は行いません。公開投稿には引き続き出典収集と審査が必要です。
