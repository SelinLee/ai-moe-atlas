Deep Whale Maid v0.3.0 / 鲸鱼娘全身细修版 / クジラ娘全身細部改良版

English
Static full-body refinement with the selected C face: larger rounded painted eyes, layered
swept hair, fine cloth edges, and a user-requested fuller, rounder whale tail.
Legs, stockings, Mary Jane shoes and unseen volumes remain inferred additions.
Open the compressed .blend in Blender 4.3.2 or later. Its default view shows the
EDITABLE collection with 181 separate, named mesh parts for direct editing.
The redundant joined export copy is omitted from the source to keep it compact.
The reproducible procedural builder is maintained in the source repository;
email-safe packages may omit executable script files.
The self-contained GLB has no external texture or decoder dependency.
No rig, skeleton, facial blendshapes, physics or animation is included.

Rebuild from the repository/package root:
ATLAS_MODEL_REVIEW_DIR=artifacts/models/deep-whale-maid/v0.3.0 blender --background --python scripts/modeling/build-whale-maid-refined.py -- --render-views
The review directory can be changed with ATLAS_MODEL_REVIEW_DIR.
The GLB is written under public/models/deep-whale-maid/v0.3.0.
